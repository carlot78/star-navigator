# assets/

Art, audio and fonts. Everything here is original or under a licence that
allows redistribution in a public repository; the licence and source of each
third-party asset is listed in `CREDITS.md` at the repository root.

- `sprites/` - ship, weapon, projectile and planet sprites (PNG, top-down, ship faces +X)
- `audio/` - music (OGG) and sound effects (WAV/OGG)
- `fonts/` - UI fonts (TTF/OTF)
